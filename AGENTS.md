# AI agent entry point

Read [agent.md](agent.md) before working on this repository. It describes the project, its verified status, open items, and the shared progress log.

Planned changes and open decisions are GitHub issues labelled `decision`; the pinned Roadmap issue (#5) lists them in order and `docs/decisions/README.md` explains the labels. Before working on a planned change, read its issue: it says why, what will change and how to check it. Start only when it has the label `status: accepted`, and make the pull request say `Closes #<number>`. If you cannot reach GitHub, ask the person you work with to paste the issue.

Keep `agent.md` current when you work here: record your task under **Active work**, then update **Current status**, **Open items**, and **Work log** when you finish. Include the files changed, validation actually performed, and any commit or blocker. Preserve Unity `.meta` files and their GUIDs when moving assets.
