# Asset provenance

The human topology, original UV layout, human morph targets, original skin weights, rig landmark definitions, skin diffuse image, and short02 hair mesh/texture derive from the MakeHuman Community's CC0 graphical assets.

- Base, targets, rig and weights: https://github.com/makehumancommunity/mpfb2
- Asset license: https://github.com/makehumancommunity/mpfb2/blob/master/LICENSE.ASSETS.md
- Skin and hair: https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html
- Pack: https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip
- Skin used: young_caucasian_male / young_lightskinned_male_diffuse.png, color adjusted.
- Hair used: short02, fitted to the morphed head and color adjusted.

The MakeHuman system asset pack explicitly lists these graphical assets as CC0. A copy of the CC0 legal text is included as MakeHuman_CC0.md. MakeHuman code is not included in the deliverable.

The prosthetic geometry, technical garment construction and details, footwear, generated material maps, display/contact geometry, preview actions, scene, export preparation, and Unity setup code were created for this request. No commercial or noncommercial-only third-party model assets were used.

Generated normal/roughness maps are procedural. The skin base-color image is the CC0 source texture, not a bespoke scan of an individual.
