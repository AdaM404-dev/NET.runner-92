# Decisions

Architecture decision records. One file per decision, named
`NNNN-short-title.md`, never edited after acceptance except to mark it
superseded by a later one.

Template:

```markdown
# NNNN — Title

Date: YYYY-MM-DD · Status: proposed | accepted | superseded by [[NNNN-...]]

## Context
What forced a decision.

## Decision
What we chose.

## Consequences
What this makes easier, harder, or rules out.
```
