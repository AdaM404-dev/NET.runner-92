# Northline release assets

## Current Windows build

Extract `NET.runner-92_Phase_07_CCTV_Windows-x64.zip` into a folder and run `Phase_07_CCTV/NETRunner92_Hospital.exe`. Keep the data folder and supporting DLLs beside it. Use [the CCTV guide](../Documentation/cctv_unity.md) for controls and [the continuation note](../Documentation/state.md) to build from source.

## Earlier checkpoints

Windows x64 archives are also prepared for `Phase_05`, `Phase_05_Optimized`, `Phase_05_Traversal`, `Phase_05_Interactive` and `Phase_06_Latch07`. Each archive name contains the checkpoint and the internal folder matches it.

## Cinematic assets

- [NET_runner_92_Intro.mp4](../Renders/NET_runner_92_Intro.mp4) is the final 60-second 1080p introduction and is tracked in Git LFS.
- `NET.runner-92_Intro_Frames_0001-0480.zip`, `NET.runner-92_Intro_Frames_0481-0960.zip` and `NET.runner-92_Intro_Frames_0961-1440.zip` extract into the same `Final_Frames` folder. Put it under `Northline/Renders` to restore the render sequence.
- `NET.runner-92_Animatic_Frames.zip` contains the earlier `Animatic_Frames` directory. Put it under `Northline/Renders/Previews` to restore the earlier sequence.
- `SHA256SUMS.txt` covers all prepared archives and the original MP4.
