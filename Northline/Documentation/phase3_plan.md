# Phase 3 production plan

This pass starts with the assembled Phase 5 Northline hospital. Phase 3 refers to the visual and cinematic brief. The archived Phase 3 patient ward model retains its original name.

1. Verify the assembled source, read the existing floor and integration notes and preserve a byte-for-byte backup.
2. Develop the hospital's 2087 material, exterior and interior language in a separate environment file. Keep all four floors, doors, stairs and gameplay clearances.
3. Stage and animate a six-part, 60-second introduction in a separate Blender project. Build and light the title as real 3D geometry.
4. Check every shot in motion against the stereo mix. Render a recoverable frame sequence, assemble the 1080p master and verify the output.
5. Reopen both Blender projects and package representative stills, title geometry, audio credits and QA notes.

## Visual direction

Northline operates in a degraded state. Warm task lights signal local activity against the colder clinical shell. Amber and red are reserved for specific functions. Rain and reflections reveal the building exterior, while isolated practicals, worn finishes and obscured equipment carry the interior story. The cinematic avoids the final lab and archive.
